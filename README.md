# Bulb Switch Project

A simple JavaScript project that simulates turning a light bulb on and off.

## Features

- Turn bulb on with the **Turn On** button
- Turn bulb off with the **Turn Off** button
- Visual glow effect when the bulb is on

## Project Structure

- `index.html` - page structure and buttons
- `index.css` - basic page styling
- `index.js` - bulb on/off interaction logic

## How to Run

1. Open `index.html` in your browser.
2. Click **Turn On** to light the bulb.
3. Click **Turn Off** to switch it off.

## Notes

- Font Awesome is used for the bulb icon.
- No build tools are required.
